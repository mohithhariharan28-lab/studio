# **App Name**: Mohith's DevFolio

## Core Features:

- Dynamic Personal Profile Display: Render and animate personal information including the hero section with a typing animation, objective, education, and certifications, pulling data from a configurable source.
- Experience & Certification Showcase: Visually present Mohith's past experiences and academic achievements, detailing roles, organizations, key contributions, and educational background.
- Interactive Project Portfolio: Showcase projects using card-based layouts with hover effects, allowing visitors to easily view titles, descriptions, and access further project details or links.
- Skills Visualizer with Progress Bars: Illustrate programming languages, tools, and concepts using animated skill progress bars for an engaging and informative presentation of technical abilities.
- Secure Contact Form Submission: Enable visitors to submit messages securely through a contact form, with all submitted data reliably stored in Firebase Firestore.
- Resume Download Facilitation: Integrate a clear and accessible button that allows visitors to download Mohith's professional resume with a single click.
- AI-Powered Inquiry Insight Tool: A generative AI tool that analyzes incoming contact form messages, summarizing their content and suggesting categories (e.g., 'Job Inquiry', 'Collaboration Request') to streamline Mohith's response process.

## Style Guidelines:

- Primary interactive color: Muted Blue (#6989BA). This sophisticated hue is ideal for interactive elements like buttons and links, providing a professional and focused appearance that stands out against a dark theme.
- Background color: Deep Charcoal (#171B1E). A very dark, almost black, tone with a subtle cool blue tint establishes an elegant and modern foundation for the entire website, consistent with the requested dark theme for the hero section.
- Accent color: Vibrant Aqua (#84D7ED). This bright, clean shade provides energetic highlights for calls-to-action, active states, and subtle graphical elements, creating effective contrast and drawing attention.
- Secondary UI colors: The user's requested shades—Azure Mist (#ECF8F8), Alabaster Grey (#EEE4E1), Almond Cream (#E7D8C9), Almond Silk (#E6BEAE), and Camel (#B2967D)—will be strategically used for text, borders, and the backgrounds of specific content cards or sections to provide textural depth and warmth within the dark theme.
- Primary and body font: 'Inter' (sans-serif). Its neutral, modern, and highly legible characteristics make it perfectly suited for all text, ensuring clarity from bold headings to detailed paragraphs in this professional portfolio.
- Clean and minimalist vector icons (e.g., from Lucide or Feather Icons) will be used consistently across the site, ensuring a sleek visual style that complements the modern aesthetic and improves navigation.
- A highly responsive, adaptive grid system that guarantees an optimal viewing experience across all device types, from mobile to desktop. The design emphasizes spaciousness, clear sectioning, and distinct card-based layouts for content like projects and experiences.
- Dynamic elements include a subtle particle animation in the hero background, a captivating typing effect for the main name heading, smooth animated progress bars for skills, and refined hover effects on project cards for enhanced user interaction.
